# 信号中心（Signal Center）需求文档

## 背景

核心用户矛盾：用户普遍只持 1–2 只股票，但对交易信号需求强烈。现有信号能力存在四层门槛：

1. **策略前置门槛**：`canEnableSignal` 强制要求 strategy_id，评估 worker 跳过空策略配置，用户必须先去策略库创建并激活策略。
2. **入口深藏**：信号配置 UI 仅存在于个股详情页「持仓 & 提醒」Tab，导航中无任何信号入口。
3. **通知门槛**：触达通道仅支持 webhook（企业微信/飞书机器人），普通用户无法配置，个股页信号区永远显示「推送未就绪」。
4. **能力约束**：`symbol_signal_configs` 为 user+symbol 唯一约束，一只股票只能配一个信号；无批量配置能力；无推荐引导。

2026-08-03 技术核实补充：盘中评估链路（腾讯 fqkline 形成中 K 线 + 5 分钟缓存 + 15 分钟 tick）是真实有效的，但缺少「盘中试算 vs 收盘确认」语义，且收盘后因交易时段门控反而无确认评估。

## 目标

1. 信号在导航「跟踪」组有独立页面（信号中心 `/signals`），提升曝光。
2. 免除策略前置：系统预置信号模板，一键开启。
3. 独立页面完成信号的配置、管理、记录查看与通知设置。
4. 自动推荐：按用户持股/自选逐股推荐信号配置，一句话理由，一键开启。
5. 可扩展：未来新增指标信号、策略信号、批量信号只需注册模板，不改前端框架。

## 功能需求

### P0 核心闭环

- F1 导航「跟踪」组新增「信号中心」`/signals`，位于自选股之后。
- F2 信号模板体系：价格提醒（涨破/跌破/单日涨跌幅）、指标信号（MACD/RSI/均线/布林等系统预置）、策略信号（绑定策略库 active 策略，兼容存量）。
- F3 订阅管理：一只股票可配多个信号；开关即点即生效；参数可覆盖模板默认值；支持对任意股票（不限自选/持仓）添加信号。
- F4 信号双状态：盘中评估产出「盘中试算」事件（bar_state=intraday_provisional），收盘后确认评估产出「收盘确认」事件（bar_state=close_confirmed）；通知与列表文案明确区分。
- F5 收盘确认评估：A 股 15:10、港股 16:10 各执行一次，补齐现有链路缺失的收盘确认信号。
- F6 信号记录页：触发历史流，按股票/方向/状态筛选；未读数映射导航角标。
- F7 通知默认站内（记录流+角标），webhook 保留为进阶折叠设置（从用户设置页迁入信号中心）。
- F8 旧 `symbol_signal_configs` 一次性迁移为「策略信号」类订阅，旧表保留不删作回滚预案。
- F9 持仓感知门控（RiskGate，2026-07-31 决策）在新订阅体系中完整保留：全量落库 + 推送门控 + suppressed_reason 归档。

### P1 推荐与联动

- F10 规则推荐引擎：按持股/自选逐股推荐模板，一句话理由，一键开启；空状态第一触点。
- F11 自选股页每行加「信号」入口；个股详情页信号区降级为该股票信号摘要 + 跳转信号中心。

### P2 批量与触达增强

- F12 批量信号：订阅 scope 支持「我的全部自选股」，一个配置覆盖多标的，评估时展开为当时自选股列表。
- F13 邮件通知通道（复用已有 mail provider）；放量类模板盘中同时段量比修正。

## 非功能需求

- 评估成本可控：订阅规模按用户数 × 1–2 股估算，盘中 tick 15 分钟，日线缓存 5 分钟兜底。
- 事件表防膨胀：同 symbol+side+trade_date+bar_state 指纹去重 + cooldown 保留。
- 合规：每条信号事件内联免责声明（沿用 SignalComplianceDisclaimer 机制）；页面保留风险提示，不得暗示收益承诺。

## 约束

- 前端遵守 `.ai/context/coding-standards.md`：语义化 Tailwind token、CSS 变量主题、红涨绿跌。
- 模板注册第一期为代码常量 + seed，不做 Admin 可编辑（对齐 D-021 原则）。
- 日期口径遵守 source_trade_date 规范；A 股/港股收盘确认按各自市场交易日历调度。
- 产品原则红线（禁止违反）：成本价仅用于盈亏展示/止损锚点，严禁"亏损不提示卖出"。

## 验收口径

- 未创建任何策略的用户，进入信号中心 3 步内（选股票 → 选模板 → 开启）完成信号配置。
- 盘中触发的信号在记录流中显示「盘中试算」标记；收盘后同策略若仍成立，生成「收盘确认」事件。
- 一只股票可同时开启 ≥2 个信号并各自独立触发。
- 旧策略信号配置迁移后行为不回归（开关状态、策略绑定、触发链路一致）。
